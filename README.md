# ⏱️Temporizador

Um temporizador digital que permite definir um período de tempo e controlar a contagem de forma simples e prática.

## Funcionalidades

- Definição de horas, minutos e segundos
- Início da contagem
- Pausa do temporizador
- Continuação da contagem
- Reinício do temporizador

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
